# 热血格斗 Online（手机上传简化版）

这是双人异地实时对战游戏的完整 Node.js 项目。文件都放在同一层，方便手机浏览器上传到 GitHub。

## Render 部署设置
- Runtime / Language: Node
- Build Command: `npm install`
- Start Command: `npm start`
- 服务类型：Web Service（不是 Static Site）

部署成功后，将获得 `https://项目名.onrender.com` 网址。把网址发给好友，双方打开后创建/加入同一房间即可。

注意：免费服务可能休眠，第一次打开需要等待启动。服务器不运行时，异地对战不会工作。
